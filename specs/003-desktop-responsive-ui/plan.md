# Implementation Plan: Desktop Responsive UI & Layout Craft

**Branch**: `003-desktop-responsive-ui` | **Date**: 2026-10-01 | **Spec**: [specs/003-desktop-responsive-ui/spec.md](./spec.md)

**Input**: Feature specification from `/specs/003-desktop-responsive-ui/spec.md`

## Summary

Deliver a desktop-responsive transformation for Minhas Horas based on the **Impeccable** skill standards and **Constitution Principle I** (Mobile-First & Cross-Platform PWA). The implementation replaces the rigid mobile phone container (`max-w-md` / 448px) on desktop viewports with an adaptive application shell featuring a dedicated desktop sidebar navigation (`w-64`), multi-column dashboard grid, structured data tables for overtime records, and centered dialog modals with keyboard shortcuts (`Escape` dismissal), while preserving 100% of the mobile bottom navigation and $\ge 44\times 44\text{px}$ touch targets on phone viewports.

## Technical Context

**Language/Version**: TypeScript 5.7.3, Node.js 22+ (ES Modules)

**Primary Dependencies**: Vue 3.5.13 (Composition API / `<script setup>`), `vue-router` 4.5.0, Tailwind CSS 3.4.17, `lucide-vue-next` 0.475.0, `dexie` 4.0.11

**Storage**: SQLite 3 (WAL mode) on server; IndexedDB via Dexie v2 on client (pure presentation feature, no schema changes required)

**Testing**: Vitest 3.0.7 (Unit, component, and layout verification tests)

**Target Platform**: Desktop Web (1080p, 1440p, 4K) + Mobile PWA (iOS WebKit / Android Chromium), self-hosted Docker on Raspberry Pi 4/5 (ARM64/AMD64)

**Project Type**: Two-tier Web Application (Fastify REST API server + Vite Vue 3 PWA client)

**Performance Goals**:
- Responsive layout transitions completed in < 100ms with zero Cumulative Layout Shift (CLS = 0)
- Zero horizontal overflow across viewports from 360px to 3840px (4K)
- Fast initial page paint and zero FOUC

**Constraints**:
- Strict adherence to Constitution Principle I: Mobile bottom navigation and $\ge 44\times 44\text{px}$ touch bounds MUST remain intact on small viewports (< 768px)
- WCAG 2.1 Level AA color contrast ($\ge 4.5:1$ text, $\ge 3:1$ UI controls) in both Light and Dark themes
- Zero added native dependencies or heavy runtime bundles

**Scale/Scope**:
- Multi-viewport responsive refactoring covering App Shell, Navigation, Dashboard, Records Table, Reports, Settings, and Entry Modals.
