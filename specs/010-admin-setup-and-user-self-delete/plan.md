# Implementation Plan: Default Admin Bootstrap with Mandatory Password Change & User Self-Service Deletion

**Branch**: `010-admin-setup-and-user-self-delete` | **Date**: 2026-10-02 | **Spec**: [spec.md](file:///home/rhoribe/lab/minhashoras/specs/010-admin-setup-and-user-self-delete/spec.md)

**Input**: Feature specification from `specs/010-admin-setup-and-user-self-delete/spec.md`

## Summary

Bootstrap a predictable initial administrator account (`admin` / `admin123`) flagged with `must_change_password`, enforcing that the password must be updated immediately upon first login before accessing any application features. Strictly enforce standard user privileges (`role: 'user'`) on all public self-registrations, preventing privilege escalation. Implement self-service account and personal data deletion in user settings with atomic cascade of overtime and compensation records while protecting the sole remaining active administrator from accidental lockout.

## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

- **Principle I: Mobile-First & Cross-Platform PWA**:
  - *Pass*. Password change view and self-service deletion modal are responsive with touch targets >= 44x44px (`min-h-[44px]`).
- **Principle II: Offline-First Operation & Deterministic Sync**:
  - *Pass*. Account self-deletion purges client IndexedDB tables and local storage to prevent obsolete records from syncing back.
- **Principle III: Minimalist Architecture & Resource Efficiency**:
  - *Pass*. Direct, cohesive extensions to existing Fastify auth/user routes, repositories, and Vue router guards without adding heavy packages.
- **Principle IV: Reliable & Lightweight Database Persistence**:
  - *Pass*. Migration 006 adds `must_change_password` column and seeds `admin` idempotently. Atomic transactions ensure complete user data eradication without orphaned records.
- **Principle V: Containerized Single-Node Deployment**:
  - *Pass*. Fully compatible with single-node Docker setup and SQLite database file persistence.
