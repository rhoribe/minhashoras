# Implementation Plan: Authentication, Multi-User Support & Impeccable Theming

**Branch**: `002-auth-multiuser-theme` | **Date**: 2026-10-01 | **Spec**: [specs/002-auth-multiuser-theme/spec.md](./spec.md)

**Input**: Feature specification from `/specs/002-auth-multiuser-theme/spec.md`

## Summary

Deliver a multi-user authentication system and high-craft design overhaul based on the Impeccable skill standards. The implementation introduces secure user registration and login utilizing Node.js built-in `crypto` (`scrypt`) and SQLite-backed session tokens, strict database and IndexedDB data partitioning by `user_id`, and an adaptive design token theming system supporting Light, Dark, and System Auto modes without FOUC, while strictly adhering to mobile-first PWA touch ergonomics (>= 44x44px) and offline-first continuity.

## Technical Context

**Language/Version**: TypeScript 5.7.3, Node.js 22+ (ES Modules)

**Primary Dependencies**: Fastify 4.28.1, `better-sqlite3` 11.8.1, Vue 3.5.13 (Composition API / `<script setup>`), `vue-router` 4.5.0, `dexie` 4.0.11, Tailwind CSS 3.4.17, `lucide-vue-next` 0.475.0, `vite-plugin-pwa` 0.21.1

**Storage**: SQLite 3 (WAL mode) on server via `better-sqlite3`; IndexedDB via Dexie v2 on client for offline caching and sync queue

**Testing**: Vitest 3.0.7 (Unit, Contract, Integration tests)

**Target Platform**: Mobile-first PWA (iOS WebKit / Android Chromium) + Desktop Web, self-hosted Docker on Raspberry Pi 4/5 (ARM64/AMD64)

**Project Type**: Two-tier Web Application (Fastify REST API server + Vite Vue 3 PWA client)

**Performance Goals**:
- Auth requests completed in < 150ms on Raspberry Pi
- Theme switching completed in < 100ms with zero layout shift or visual flash (FOUC)
- Memory usage baseline < 200MB

**Constraints**:
- Must preserve offline-first capability (logged-in user can record entries offline)
- Zero external C++ native build dependencies for auth (relying on Node built-in `crypto`)
- Strict WCAG 2.1 Level AA color contrast (>= 4.5:1 text, >= 3:1 UI controls)

**Scale/Scope**:
- Multi-user self-hosted deployment (1 - 50 active users per instance)
- Complete UI polish covering navigation, login screen, theme toggling, and data segregation
