# Implementation Plan: Dynamic Positive Limit Ceiling on Dashboard

**Branch**: `013-dashboard-ceiling-limit` | **Date**: 2026-10-02 | **Spec**: [spec.md](file:///home/rhoribe/lab/minhashoras/specs/013-dashboard-ceiling-limit/spec.md)

**Input**: Feature specification from `specs/013-dashboard-ceiling-limit/spec.md`

## Summary

The dashboard balance card currently displays a static ceiling label `"Uso do teto (+40h)"` regardless of what value the user sets in **Configurações > Limites de Segurança do Banco > Limite Máximo Positivo**. Furthermore, client-side balance calculations (`calculateLocalBalance`) hardcode the ceiling at 2400 minutes (40h) and do not read user settings from IndexedDB or the server.

The solution provides an offline-first, dynamic ceiling architecture:
1. Cache user time bank settings in IndexedDB (`localDb.preferences`) upon retrieval, modification, or background sync.
2. Update `calculateLocalBalance()` in `client/src/services/balance-service.ts` to retrieve the active user's cached positive limit (falling back to 40h/2400m if unconfigured).
3. Ensure `BalanceCard.vue` formats the ceiling string dynamically (e.g. `+20h`, `+60h`, or `+20h 30m`) and computes progress bar percentage against the user's actual positive limit.
4. Keep `LimitAlertBanner.vue` thresholds synchronized with the user's custom ceiling.
